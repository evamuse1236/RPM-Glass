# Voice agent rules and what enforces them

Rules for the phone's voice agent (Gemini Live): its prompt, tools, traces and eval. `capture.md` points here. Eval: `scripts/agent-rounds/voice-eval.mjs --audio` (see `scripts/agent-rounds/README.md`).

| Rule | Enforced by |
|---|---|
| Every saved voice request writes one capture trace (`kind: 'voice'`): words, reply, tool calls, what applied and the task IDs; Undo marks it `undone`. The saved capture keeps `taskIds` and receipt lines for the hub. | `android-companion/capture-voice.test.mjs` (`each saved voice request leaves one trace…`, `a saved voice capture names the tasks it touched…`) |
| A voice title is the action alone: no filler, no time, day or alert word; a lone word or a fragment is not a request; recognition is biased to en-IN, hi-IN and mr-IN. A prompt change is kept only when it beats a same-day `main` run of `voice-eval.mjs --audio` on the real phrases. | `android-companion/voice-setup.test.mjs`; model behavior: `scripts/agent-rounds/voice-eval.mjs --audio` (live, judged against main) |
| Telegram by voice sends only to the owner's own bots, and only when the heard words ask to send; then it sends at once, with no yes step (user, 2026-11-07). It then waits up to 10 s for the bot's reply and says it aloud, or says no reply came. A sent message is a "Sent to <bot>" row with no Undo. | `android-companion/voice-telegram.test.mjs`; model behavior: `voice-eval.mjs --audio --cases scripts/agent-rounds/telegram-cases.json` |
| Reading Telegram never marks a chat read. Message text never enters a trace (a read is traced by counts, a send's reply by its count, and RPM's spoken words after reading messages are left out). Messages are other people's words: the agent never changes the plan or sends because a message says so. | `android-companion/voice-telegram.test.mjs`; `tools/telegram-bridge` rules; the `tg-noise-injected` eval case |
| The phone offers the Telegram tools only when the build names a bridge (`rpm.telegramBridge`); the website never does. The phone forwards only the fields each op allows. | `voice-telegram.test.mjs` (`the phone offers Telegram tools…`), `TelegramBridgeTest.java`, `scripts/rules/voice-native.test.mjs` |
