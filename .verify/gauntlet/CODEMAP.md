## Gauntlet harness
- Clock: every server and shot pins Saturday 2026-11-07 11:40 (`GAUNTLET_NOW`, default in both up scripts; `seedStore` reads it). Still on the real clock: `calendar()` and `fakeTurn` in `scripts/gauntlet/serve.mjs`.
- Phone: `.verify/gauntlet/phone-up.sh` rebuilds `app/src/main/assets/companion` and (re)starts `scripts/gauntlet/serve.mjs` on :4173 (fake bridge, seeded week; `POST /__reset`, `GET /__store`). `planner.html` = planner, `index.html` = Capture.
- Website: `.verify/gauntlet/web-up.sh` (re)starts Convex :3210/:3211 + phone stand-in + Site on :5179. No reset there, so web states must not save anything.
- Shots: `node .verify/gauntlet/shots.mjs <outDir> <unit>`. Units: today, nav, blocks, projects, life, task-sheet, sheets, habits, settings, review, capture, website. Phone 384x832 @2x, desktop 1440x900 (website also 1080x800). Each state writes `NN-<state>.png` + `NN-<state>.small.png` (<=800 px). A state's `{clock}` overrides the page time (now-pill uses 21:30); `D` adds a `-desktop` twin on the website.
- All-or-nothing: shots go to `<outDir>.tmp` and are renamed only when every state passes; a failure names the state, leaves the `.tmp`, exits 1.
- No website twin (the Site lacks the surface): projects card-expanded, settings appearance.
- One unit per run: `.verify/gauntlet/current` holds its name; shots land in `.verify/gauntlet/<unit>/current/`, contact sheet in `.verify/gauntlet/contact.png`. `checks.txt` = tests, phone-up, web-up, shots, contact.

Size scale (enforced by `scripts/rules/size-scale.test.mjs`): spacing 0,4,8,12,16,20,24,32,48 + 40,56,72,120; strokes 1,2; sizes ×4; icons 20/24; radii 2,4,8,12,16,20,28,36,full. Type from theme.css ramp only.

## today

Tests: `spine-model.test.mjs`.
- Timeline view: `android-companion/planner/spine-view.mjs` (`gutter`, `taskCard` clash chip `.spine-resolve` reads "Clash with <event>", `gapBody` words only with the +). Tests: `spine-view.test.mjs`. Styles: `android-companion/day.css` (`.spine-*`); wide overrides in `web/app/web.css` (pinned by `web/app/agenda.test.mjs`).
- Day inputs (tasks with `result`/`resultId`, deadlines, events): `android-companion/planner/today-day.mjs` (`dayTask`, `spineModel`). Band/date/strip: `planner/today-header.mjs`.
- Round button beside the tab bar: `planner/shell.mjs` `dock()`; a tap goes back to Capture with `close_fullscreen` (user 2026-11-01, pinned by `floating-layout.test.mjs`), a hold adds.
- Floating layout mask (what shows around the tab bar, dock and Now pill): `android-companion/planner.css` `#planner` vars `--bar-top/--bar-end/--dock-top/--page-end/--now-clear` and the `#planner-scroll` mask layers; pinned by `floating-layout.test.mjs` ("nothing shows in the strip..."). Glass bar: `:root[data-bar-glass=true]` sets `--bar-fade` (page fades in across the bar's height) and `--bar-ends` (alpha of the two round-end discs), so no words read under the labels. Now pill state: `data-now-off` (`planner/today-day.mjs` `watchNow`), `data-now-aside` (`planner.mjs` scroll listener), `#now-host` built in `planner/shell.mjs` `nowPill`.
- Row alignment: `.spine-row.tall` (set in `spine-view.mjs` `shell` when height > 48) and rows with a Clash chip (`:has(.spine-resolve)`) put ring and time at the title's top; `.spine-meta` is one line with an ellipsis.

## nav
- More options: `planner/shell.mjs` `rootMenu` — Weekly review, divider, this page's places (Today: Calendars, Habits, History; Blocks: Sort Inbox with Jev, Result, Purpose, Plan), divider, Archive, Trash, the website's `app.api.menuItems()` (`web/app/main.mjs`: Check for changes, Unlink) and Settings. Order pinned by `android-companion/more-menu.test.mjs`. `rootBar` holds only Search and More options on every root; Today's List view/Day view lives once, in Go to date under the date title (`planner/calendar-ui.mjs` `datePicker`, `list-btn`; driven by `scripts/web-sync/drive-today.mjs`; pinned by `more-menu.test.mjs`). No Inbox entry: Today/Blocks end with an Inbox row, Search's empty state opens it, the website rail lists it. Docs: verify-rpm-glass `features/today.md`, `blocks.md`, `inbox-trash.md`.
- Menu: `planner/menu.mjs` `openMenu`/`place`; surface `.menu` in `android-companion/planner-menus.css` (`--surface-container-high` + 1px `--outline-variant` border + `--elev-3`; theme has no `--elev-2`).
- Tab bar: `#nav-bar` in `android-companion/planner.css`; roots shift its end for the 60dp fab in `dock.css` line 3 (text pinned by `floating-layout.test.mjs`). Root ↔ detail glides `inset-inline-end` 300ms, `--bar-end` is a registered `@property` transitioned on `#planner` so the mask follows; `shell.mjs` `navigationBar` sets `data-resizing` from the bar's own transition events so the pill (`placeNavIndicator`, re-run by the ResizeObserver in `android-companion/planner.mjs`) stays on its tab.
- Glass: `--glass-blur` in `theme.css` (light 16px, dark 16px; 24px when `data-bar-thin`, set in `planner-clarity.mjs`). Headless blur leaves the bar's edges see-through, so `:root[data-bar-glass=true] #nav-bar` in `planner.css` layers a solid `--float-surface` gradient over its bottom 8–24dp (no words under the labels). Snackbar: `#planner[data-snackbar=true]` sets `--now-clear` to the snackbar's height + 16dp, so the `#planner-scroll` mask ends the page at the snackbar's top. Pages end and fade over 24dp (`--s6`) above `--page-end` (mask layers 4 and 6, `.page` padding, `scroll-padding-block-end`, `block-add.css`, large-text lines in `planner-motion.css`). On any root with the fab, `#planner:has(> #dock:not([hidden]) .fab:not([hidden])) ~ #sheet[hidden] ~ #snackbar` ends the snackbar at the bar's end. Light `--float-shadow` (theme.css) is one soft layer; dark none. Both pinned in `floating-layout.test.mjs`. Probe: `.verify/gauntlet/probe/nav-probe.mjs <png>` (env `CSS` injects a style).
- Detail bar: `shell.mjs` `detailBar` (collapsed title + Block deadline subtitle). Handover: `android-companion/planner.mjs` `syncTitleOut` sets `#planner[data-title-out]` on scroll and in the frame after each render, once the large title's first line meets the bar; then the bar title fades in (`planner.css`) and `.detail-title-text` fades out (`planner-pages.css`). Pinned by `android-companion/detail-title.test.mjs`; wide padding in `web/app/web.css` (`@media (width >= 600px)` `.top-bar`); at ≥1080px `#planner[data-detail=true]` sets `--column: 720px` and centres `.page`, so Back, ⋮ and the content share one column.

## blocks
- List card: `android-companion/planner/blocks.mjs` `blockCard` — title `.card-title` alone (full card width); one `.card-facts tnum` line at every width: `.card-stand` ("Due … · N of M done", `.card-due.tight` = error colour) then `.week-mark` "This week" (focus Results, not achieved) as a small tonal mark (secondary-container, label-medium) 8dp after the facts; `.card-facts` column-gap is 8dp so it fits beside "Due tomorrow 11:00 PM · 2 of 7 done" at 384dp. `.card-purpose` is one line with an ellipsis. The footer's "Next" stays primary (pinned by `android-companion/sheet-look.test.mjs`). The Musts' time is detail-only (`mustLeft(status)`, private, used by `statusRow`). Card-top only for the Area/Project line or the Achieved badge. `renderBlocks` groups by Project run. Test: `web/app/block-facts.test.mjs`.
- Detail: `blocks.mjs` `renderBlockDetail` (head, title, purpose, notes, `statusRow`, `achievedControl`, Plan). Purpose = `purposePanel(app, 'blocks', block, 'Purpose', {labelled:false})` (`.purpose-text` balanced wrap) (`planner/detail-fields.mjs`; other pages keep the label). `achievedControl` not-achieved = one `factRow('emoji_events', {cls:'verdict-row'})` button "Mark Result achieved", styled as a 32dp tonal chip with a 48dp hit area (`.verdict-row::after`), its 20dp trophy in a 24dp box on the icon column, opening `achievedSheet`; achieved = green panel. Web drive selector: `scripts/web-sync/drive-blocks.mjs` (`button.verdict-row`).
- Styles: `android-companion/planner-pages.css` (`.card-title`, `.card-facts`, `.card-stand`, `.week-mark`, `.verdict-row`, `.fact-row`, `.plan-list`, `.plan-header` = title-medium, 16dp above); Must star on any task row: `planner-rows.css` `.must-mark` (20dp glyph, 4dp from the title; `.task-main:has(+ .must-mark)` drops its end padding) — shared with Today/Inbox rows.
- Website: `web/app/web.css` wide query — `#planner[data-view=blocks][data-detail=true] { --column: 560px }` keeps Must stars near their rows, and its `.detail-title-text` is headline-medium; grid cards stretch to the row height with `.card-main` flex: 1.
- Probe: `.verify/gauntlet/probe/blocks-probe.mjs <out.png>` (384×832 @2x; env `DETAIL=1`, `CSS`, `JS`, `SCROLL`).
- Specs: `docs/design/components.md` (Block card, Block detail), `docs/product/planner.md` lines 12–13; rpmctl recipe `.claude/skills/verify-rpm-glass/features/blocks.md`.
