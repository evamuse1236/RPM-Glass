# Retro 2026-10-27: tooling backlog

The web-standalone retro found these gaps. The cheap ones were built in the same session (see `log.md`). These need more than an hour or a design choice first.

| Gap | What happened | Mechanism to build |
|---|---|---|
| The Stop hook's evidence gate fires on every turn while unproven app changes sit on the branch, even turns that only wait on sub-agents. | About 10 turns answered "this turn changed no app behavior". The files came from the base branch `fix/flaws-2026-10-26`, which was not on main. | Open design choice: the files were unproven app changes the branch carried, so skipping them is wrong. Options: block once per unchanged tree state, or record the session-start HEAD and block the stop only for files changed since then, while `check:merge` keeps the full diff. Prototype both against `scripts/rules/require-evidence.test.mjs`. |
| `web-sync-offline` is outside `scenario --all`, so the merge gate never runs the feature's own end-to-end check. | CI went green by expecting fewer scenarios. The scenario last ran before the main merge and the task ID fix. | Scenarios declare the paths they guard, and `check:merge` needs a passing run of each scenario whose paths changed. Or the CI workflow starts a local Convex, so the scenario joins `--all`. |
| The sync test fake reuses the code under test, so it proves wiring but not ordering. | The Node stand-in passed. The real app then lost a newer website edit to an offline phone edit. | A randomized sequence test in `android-companion/replica-sync.test.mjs`: phone ops, server ops and network faults against `fakeServer`. It asserts no value is lost without a conflict row. |
| The server Capture path has no corpus-level live eval. | Only `stress:capture --transport api` (the phone pipeline) ran against `main`. | `stress:capture --transport convex` through the local Convex action, required by `check:evidence` when `convex/capture*` changes. |
| The live eval has no built-in `main` baseline. | The 60/66 score meant something only after a hand-run of `main` (59/66). | `stress:capture --baseline main` runs the same phrases in a clean `main` worktree and prints the difference. |
| Migration rehearsals have no reusable local stack. | `convex dev --once` exited before the import, and a leftover backend held port 3210. | A persistent local stack with readiness checks and owned-process cleanup in `scripts/web-sync/`. |
| Release steps are ordered by hand. | A version bump after staging the Site forced a second deploy. | `npm run release`: bump, `check:merge`, merge, backup and Convex deploy, stage, push the Site source, deploy, mark, APK. |
